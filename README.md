# Forward We Grow

A founder-led home for Sarah Landis and Forward We Grow, bringing together yoga, wellbeing, retreats, community, art and creativity.

## Development

```bash
npm install
npm run dev
```

## Before public launch

- Replace editorial placeholder photography with Sarah's own photographs and assets she has permission to use.
- Confirm Sarah's preferred biography and approve all first-person website copy.
- Verify current retreat, yoga, art and collaboration offerings, prices, dates and booking links.
- Connect a real enquiry form and mailing-list provider; current calls to action open the Forward We Grow Instagram account.
- Confirm the correct domain and social links.
- Test the site on mobile and desktop.

This first version is a design prototype, not an officially approved or operational business website.
